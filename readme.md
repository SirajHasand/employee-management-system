# Employee Management System API

## 📌 Project Overview

This project is a RESTful Employee Management System built using:

- Node.js
- Express.js
- PostgreSQL

It manages:

- Departments
- Positions
- Employees
- Addresses
- Salaries
- Documents
- Attendance

The project is being developed step-by-step during my internship at the Ministry of Finance to practice real-world backend development concepts.

---

## 🗄️ Database Structure

Main Tables:

- Department
- Position
- Employee
- EmployeeAddress
- EmployeeSalary
- EmployeeDocument
- EmployeeAttendance

The system uses:
- Foreign Keys
- Unique Constraints
- Indexes for performance
- Soft Delete (IsDeleted)
